Fake Review Detection System

A Machine Learning based web application used to detect fake product reviews and classify them as genuine or fake.

## 📌 Features

- Detects fake reviews using Machine Learning
- User-friendly interface
- Review text analysis
- Fast prediction system
- Simple and responsive design

## 🛠 Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
